управления сервисами на VPS **по SSH без агентов на серверах**. Язык общения с пользователем — **русский**.

## Инварианты, которые НЕЛЬЗЯ нарушать

- **Источник истины типов — Zod в `packages/shared`.** Меняешь форму данных → сначала схема, потом код. Не дублируй типы.
- **Схему БД меняй через `pnpm db:push`, НЕ через миграции** (`db:generate`/`db:migrate` — только по явной просьбе).
- **После любого изменения кода — `pnpm typecheck` + `pnpm lint` + `pnpm test`** (Vitest: чистые функции). CI нет; проверка = typecheck + lint (0 errors) + test + ручной e2e через curl. Менял чистую функцию (парсер/crypto/config) — добавь тест рядом (`*.test.ts`). ESLint — flat-config, type-aware; идиоматичный fire-and-forget помечай `void`.
- **Секреты и приватные ключи всегда шифруются** (`encryptSecret`, AES-256-GCM) до записи в БД. Публичные типы (`*Public`) и API-ответы их не содержат.
- **Веб-терминал = прямой shell к серверу.** Auth на `/ws` не ослаблять; любой новый WS-канал с доступом к серверу — за проверкой сессии. Не логировать секреты и содержимое терминала.
- **ESM везде:** относительные импорты с расширением `.js` (даже для `.ts`).
